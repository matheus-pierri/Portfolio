Reporting Process Automation

Independently identified and automated a repetitive weekly reporting workflow using Microsoft Power Automate and SharePoint, reducing manual file collection and creating a scalable process for similar project reporting cycles.

Initiative Self-Directed
Platform Power Automate + SharePoint
Initial Saving ≈ 30 min/week
Scale Potential ≈ 2 h/week

01 · The Opportunity

Automating Work I Was Already Doing Manually

Part of my recurring reporting work required locating and collecting files from SharePoint each week before the analysis could begin.

The task was simple but repetitive, so during available downtime I began teaching myself Microsoft Power Automate and gradually developed a workflow to handle the process automatically.

This was not an assigned project. It grew from noticing a recurring inefficiency in my own work and deciding that the process could be improved.

04 · What I Took From It

Initiative, Automation & Continuous Improvement

Learn New Tools When They Solve a Problem

I had not been brought into the internship as a Power Automate specialist. I learned the platform because it offered a practical way to remove unnecessary manual work.

Improve the Process, Not Just the Output

The analysis itself still mattered, but improving how inputs were gathered made the entire reporting cycle faster and more repeatable.

Look for Scalable Improvements

A small weekly saving becomes much more valuable when the same structure can be reused across several similar project workflows.
